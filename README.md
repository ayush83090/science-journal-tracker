🧠 Scientific Journal Tracker

An AI-powered web application that helps users discover, track, and summarize the latest scientific research papers using an interactive chatbot interface.

🚀 Overview

The Scientific Journal Tracker is designed to simplify access to newly published research by integrating AI-driven summarization with a modern web interface. Users can ask queries and receive concise, relevant journal insights in real time.

✨ Features
🤖 AI-powered chatbot for journal queries
📄 Real-time research paper retrieval
🧠 Automatic summarization of scientific content
🎨 Modern, dark-themed interactive UI
⚡ Dynamic response rendering on the same page
🛠️ Tech Stack
Backend: Python, Flask
AI Integration: Gemini API
Frontend: HTML, CSS, JavaScript
Design: Responsive and interactive UI
🧩 How It Works
User enters a query in the chatbot
Backend processes the request using AI API
Relevant journal data is fetched
AI summarizes the content
Results are displayed dynamically on the interface
